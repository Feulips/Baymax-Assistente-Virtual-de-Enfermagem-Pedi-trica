
# 🩺🤖 Baymax – Assistente Virtual de Enfermagem Pediátrica  
**(PHP + HTML + CSS + JS + Gemini Integrado)**

**Baymax** é um chatbot inteligente inspirado no personagem icônico de *Operação Big Hero*. Desenvolvido com **PHP, HTML, CSS e JavaScript**, ele utiliza o poder do **Google Gemini** para oferecer respostas claras, rápidas e acolhedoras sobre **enfermagem pediátrica**.

Com um visual minimalista, branco e redondinho — remetendo ao Baymax original — o bot transmite calma, cuidado e segurança. Ele foi pensado para acompanhar estudantes e profissionais na rotina pediátrica, respondendo dúvidas sobre sinais vitais, procedimentos, medicações e orientações para familiares.

## 💡 O Baymax digital oferece:
- **Tema Baymax:** interface fofa, suave e acolhedora, inspirada no robô cuidador.  
- **Comunicação empática:** mensagens no estilo Baymax (“Olá, eu sou o Baymax, seu assistente de cuidados. Como posso ajudar hoje?”).  
- **Gemini integrado:** respostas inteligentes, atualizadas e adaptadas ao contexto pediátrico.  
- **Frontend moderno:** HTML + CSS com visual limpo e JS para conversas fluidas.  
- **Backend em PHP:** responsável por enviar mensagens ao Gemini e retornar respostas.  
- **Especialização em Pediatria:** ideal para estudar, revisar e consultar cuidados essenciais.

**O Baymax traz tecnologia e carinho no mesmo lugar — um companheiro digital para quem cuida de crianças e precisa de apoio inteligente e gentil.**
