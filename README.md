# Baymax-Assistente-Virtual-de-Enfermagem-Pedi-trica
🩺🤖 Baymax – Assistente Virtual de Enfermagem Pediátrica Chatbot inspirado no Baymax, feito em PHP, HTML, CSS e JS, integrado ao Gemini. Responde dúvidas sobre cuidados pediátricos com clareza e acolhimento. Visual minimalista, comunicação empática e foco total em sinais vitais, procedimentos e orientações para familiares.
